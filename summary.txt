Assignment Overview
This project implements a multi-threaded, distributed Key-Value Store using Remote Procedure Calls (RPC) with Java RMI. The primary objective is to replicate the Key-Value Store across five distinct servers to enhance system bandwidth and availability. The client should be able to issue PUT, GET, and DELETE operations to any of the five replicas while maintaining data consistency across all replicas. To ensure strong consistency, this project implements the Two-Phase Commit (2PC) protocol, which guarantees that PUT and DELETE operations are either committed on all replicas or aborted entirely. The system assumes no server failures during execution, but the implementation is designed to handle potential network communication failures gracefully.

Each server registers itself via Java RMI, allowing clients and other replicas to look up and invoke remote methods. A client randomly selects one of the five servers to connect to and performs a series of operations (5 PUTs, 5 GETs, and 5 DELETEs). The implementation ensures that each operation is performed concurrently and safely using ConcurrentHashMap for data storage and ReentrantReadWriteLock for thread synchronization. Overall, this project demonstrates distributed system principles, consistency guarantees, and fault-tolerant transaction management using 2PC over RPC.
